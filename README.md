This repository is about my learning journey through Getting Started with Cisco Packet Tracer on Cisco Networking Academy.

In this course, I learned how to use Packet Tracer, explore its interface, work with virtual networking devices, and create a simple network. It was a good starting point for understanding how network simulations work.

- Platform: Cisco Networking Academy
- Level: Beginner
- Duration: Approximately 2 hours
- Status: Completed ✅

🔗 "Course Link" (https://www.netacad.com/courses/getting-started-cisco-packet-tracer/1000)

🧩 What I Learned

Module 1: Download and Use Cisco Packet Tracer

This module introduced me to Packet Tracer and showed me how to get started with it.

Here are some of the things I learned:

- How to download and launch Cisco Packet Tracer.
- How to explore and use its interface.
- How to find and add networking devices.
- The difference between GUI and CLI.
- The difference between Logical Mode and Physical Mode.
- How to explore the software through guided activities.

This module helped me get familiar with the tool and understand how it can be used to practice networking without needing physical devices.

Module 2: Create a Cisco Packet Tracer Network

In this module, I moved from exploring the software to learning how to create a network.

I learned about:

- Packet Tracer file types, including ".pkt" and ".pka".
- How Packet Tracer activities and assessments work.
- How to create a simple home network.
- Some of the additional features available in Packet Tracer.

This module helped me understand how different devices can be brought together in a simulated network.

🛠️ Tools and Concepts

Here are some of the tools and concepts I explored during the course:

- Cisco Packet Tracer: A tool for building and testing virtual networks.
- GUI: A way to interact with software using visual elements.
- CLI: A way to interact with a device by entering commands.
- Logical Mode: Used to build and view a network's layout.
- Physical Mode: Used to explore the physical layout of a network.
- ".pkt" files: Used to save Packet Tracer network projects.
- ".pka" files: Used for Packet Tracer activities and assessments.
