## The main ideas

- Packet Tracer is a **free network simulator**. You can practice networking, IoT, and cybersecurity with it.
- It has **two main views**: *logical* (how devices connect and how data flows) and *physical* (racks, cables, ports).
- It also has **two modes**: *real-time* (things just happen) and *simulation* (you control time and watch packets move).
- Every device has **tabs** like Physical, Config, CLI, Desktop, and Services. Which ones you see depends on the device.
- The **Config tab** is the beginner-friendly GUI, and it shows you the matching CLI commands as you click. Kind of a cheat sheet that teaches you.
- A **PTTA** (Packet Tracer Tutored Activity) is a guided activity with adjustable hints, like a teacher looking over your shoulder.
