## The main ideas

- There are **four file types**: `.pka` (activity), `.pkt` (a saved network), `.pksz` (tutored activity), and `.pkz` (old, deprecated).
- A **.pka** file has an instructions window and scoring. It secretly holds two networks: the one you work on, and an **answer network** running in the background for grading.
- A **.pkt** file is just a network you built and saved. No instructions, no scoring.
- Packet Tracer shows up in assessments in two ways: **PTMO** (a file inside a quiz question) and **PTSA** (a full standalone skills test).
- You can find a device's IP info in **two ways**: the Config tab, or the command prompt on the Desktop tab.
- **Static** addresses are typed in by hand. **DHCP** addresses are handed out automatically (they show up grayed out).
- You can add a **background image** (like a city map) to the workspace so your topology matches a real place.
